Política de privacidad

Fecha de entrada en vigor: 18 de noviembre de 2026.

1. Finalidad y responsable

ViceCityPlatinum es un canal independiente de contenido sobre GTA VI. Su herramienta de escritorio es para uso exclusivo del propietario del canal y está diseñada para gestionar vídeos propios mediante YouTube Data API v3. Esta web es únicamente informativa. Para consultas sobre la aplicación o sobre datos personales, utiliza el correo de contacto del canal malagacreate@gmail.com.

2. Datos de YouTube utilizados

Con autorización expresa del titular de la cuenta mediante OAuth 2.0, la aplicación solicita los permisos necesarios para subir vídeos y consultar vídeos del canal, así como sus datos asociados (por ejemplo, identificadores, títulos y estado de publicación). No pide a visitantes de esta web autorización de acceso a Google.

3. Integraciones en preparación

Cuando la prueba de TikTok esté habilitada y el titular dé su consentimiento, la aplicación usará el identificador de la cuenta, los datos básicos de perfil disponibles con Login Kit y los permisos para enviar a TikTok los vídeos propios seleccionados como borradores. TikTok recibe el archivo y permite al titular decidir en su aplicación si completa la publicación.

Facebook, Instagram, Threads y X son integraciones previstas. Antes de habilitar cada una, esta política indicará los permisos que se solicitan, los datos utilizados y cómo revocar el acceso.

4. Uso y almacenamiento

La aplicación está diseñada para mantener localmente las credenciales y los tokens OAuth necesarios para las operaciones autorizadas. Estos datos no deben incluirse en el repositorio web público. Los datos obtenidos de las API de Google no se utilizan para publicidad, perfiles comerciales, venta ni transferencia a terceros.

5. Compartición y tratamiento

La aplicación transmite a cada plataforma conectada los archivos y datos necesarios para las operaciones autorizadas por el titular. Las plataformas tratan esa información conforme a sus propias condiciones y políticas. El proyecto no vende los datos obtenidos de las API ni los utiliza para publicidad o perfiles comerciales.

6. Conservación, eliminación y revocación

Los tokens locales se conservan mientras sean necesarios para mantener el acceso autorizado. El titular puede revocar los permisos desde Conexiones de la cuenta de Google y eliminar los tokens almacenados en su ordenador. La revocación detiene nuevas operaciones hasta autorizar de nuevo; no elimina automáticamente vídeos ya subidos. Cuando esté habilitada la prueba de TikTok, el titular podrá retirar el acceso de la aplicación desde los ajustes de seguridad y permisos de su cuenta de TikTok y eliminar del ordenador las credenciales locales correspondientes.

7. Visitantes del sitio

Esta web estática no incorpora formularios, analítica propia ni cookies añadidas por ViceCityPlatinum. GitHub Pages, como proveedor de alojamiento, puede procesar información técnica conforme a la declaración de privacidad de GitHub.

8. Servicios externos

El uso de YouTube se rige por los Términos del Servicio de YouTube, la Política de Privacidad de Google y las reglas para datos de usuario de las API de Google.

9. Cambios

Esta política se revisará cuando cambien las funciones de la herramienta o su tratamiento real de datos. La versión vigente permanecerá accesible en esta página.
