Sobre nuestra herramienta de publicación

ViceCityPlatinum desarrolla una aplicación privada de escritorio para que el propietario del canal gestione sus propios vídeos mediante YouTube Data API v3. La herramienta está diseñada para subir vídeos inicialmente en modo privado y consultar los vídeos del canal con autorización OAuth 2.0.

No es una aplicación abierta a otros usuarios. Los visitantes de esta web no necesitan conectar su cuenta de Google ni facilitar datos personales.
